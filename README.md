# OneDrive Cinema

A fast, scalable media streaming web app (Netflix/Plex-style UX) powered by Microsoft OneDrive + Graph API.

## Quick start

1. Copy env file and configure Microsoft OAuth app credentials.
   ```bash
   cp .env.example .env
   ```
2. Install + run.
   ```bash
   npm install
   npm start
   ```
3. Open `http://localhost:3000` and click **Connect OneDrive**.

Detailed architecture and deliverables: `docs/IMPLEMENTATION.md`.
